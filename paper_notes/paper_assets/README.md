# Paper Assets

Publication-ready figures (PDF + PNG) and LaTeX tables generated from the final, post-fix
results.

## Figures (`figures/`)

- **fig1_claim1_role_vs_random** — grouped bar chart, role-specific vs random-mean advantage by
  setting and sparsity. Suggested as Figure 1 (the paper's headline visual).
- **fig2_claim2_compensation_forest** — forest plot of role-specific vs unmasked across every
  calibration draw and sparsity on Qwen-arithmetic. Shows the "holds everywhere except one
  atypical draw" picture at a glance.
- **fig3_mask_overlap_heatmap** — Jaccard-overlap heatmaps between role-pair masks, one panel per
  model/domain. Supports the shared-capacity hypothesis (critic/verifier overlap far more than
  any other pair, consistently).
- **fig4_entropy_diagnostic** — CV vs. normalized entropy scatter, one point per activation-stats
  checkpoint, colored by model. Supports the Discussion-level link between the entropy diagnostic
  and the shared-capacity hypothesis.

Use the `.pdf` versions in the LaTeX source (vector, scales cleanly); `.png` are for quick
preview/slides.

## Tables (`tables/`)

Each `.tex` file is a standalone `table` environment using `booktabs` — `\input{}` it directly
into the paper, or copy the `tabular` body into an existing float. All require
`\usepackage{booktabs}` in the preamble.

- `table_absolute_accuracy.tex` — **Table 1 candidate**: absolute accuracies (unmasked/role/generic/random)
  + role − random and role − agnostic with CIs, all 12 settings (`table*`, generated, label `tab:absolute`).
- `table_claim1.tex` — Claim 1, all 12 settings (compact Δ-only version).
- `table_claim2_compensation.tex` — Claim 2a (team-level robustness; filename kept from when it
  was called "compensation"), all 12 calibration-draw x sparsity cells, label
  `tab:claim2-robustness`.
- `table_claim2_assignment.tex` — Claim 2b, assignment invariance, Qwen + bAbI panels, role − reassigned (`table*`, generated, label `tab:swap`).
- `table_mask_overlap.tex` — role-pair Jaccard overlap, 3 models side by side (complements
  fig3's heatmap with exact numbers; use one or the other, not both, to avoid redundancy).
- `table_entropy_diagnostic.tex` — entropy/CV diagnostic summary (complements fig4).
- `table_persona_probe.tex` — pre-registered persona probe (SmolLM2 bAbI, 5/10/15%), instruction vs. persona, role − X (`table*`, generated, label `tab:persona`).

## Regenerating

Data-driven tables (absolute accuracy, assignment, persona):

```powershell
$env:PYTHONPATH='src'; .venv\Scripts\python.exe scripts\generate_paper_tables.py
```

Figures:

```powershell
.venv\Scripts\python.exe scripts\generate_paper_assets.py
```

`scripts/generate_paper_assets.py` computes fig1 from the predictions (10-draw random
baselines), has the Claim 2 numbers for fig2 hardcoded, and recomputes the mask-overlap and
entropy figures from `artifacts/`. `table_claim2_compensation.tex`, `table_mask_overlap.tex` and
`table_entropy_diagnostic.tex` are hand-authored; all other tables are generated by
`scripts/generate_paper_tables.py`.
